Model

A multiple regression modeled the overall efficiency rating (Q37r, 1 = very poor, 5 = excellent) using Q31–Q34. Seven respondents lacked a valid Q37r rating, leaving 121 for analysis.

library(haven)
library(knitr)

survey <- read_sav("Case 31 Data_efcu_4.sav")
names(survey) <- tolower(names(survey))
fit <- lm(q37_r ~ q31 + q32 + q33 + q34, data = survey)
model_summary <- summary(fit)
f <- model_summary$fstatistic
model_p <- pf(f[1], f[2], f[3], lower.tail = FALSE)

Results

The model explained 30.1% of the variation in ratings (adjusted R² = .276, F(4, 116) = 12.46, p < .001).

Hypothesis decisions

Each coefficient is the change in the efficiency rating per one-point increase in the predictor, holding the other three constant. Decisions use two-sided tests at α = .05.

  • H5a supported. Confidentiality was positively associated with efficiency (b = 0.19, p = .036).
  • H5b supported. Prompt loan processing had the largest positive coefficient (b = 0.31, p < .001).
  • H5c supported. Meeting member needs was positively associated with efficiency (b = 0.29, p < .001).
  • H5d unsupported. The estimate for ease of completing loan applications was inconclusive (b = −0.07, p = .390).
