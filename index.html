Analysis notes

Use valid responses for each analysis and exclude “no opinion” from numerical ratings. Q11–Q12 are binary in the measurement key. If Q11–Q12rc remain binary after recoding, summarize them as percentages and use chi-square tests for the R4c comparisons. For H2, interpret the difference as a comparison of coded scores because the two questions have different response anchors.
